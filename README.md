## About Me

I’m a developer who cares about building software that is not only functional, but also **structured, maintainable, and genuinely useful**.

Right now, my core strength is in **Java and backend development**, while I’m actively expanding into **TypeScript, React, Next.js, APIs, and fullstack architecture**.

I’m especially interested in software that combines:

- solid engineering
- clean system design
- polished user experience
- real product value

I’m not aiming to build random tutorial clones.  
I want to build things that solve actual problems, look professional, and scale properly.

---

## Philosophy

I like software that is:

- **clean instead of chaotic**
- **fast instead of bloated**
- **useful instead of decorative**
- **clear instead of overengineered**
- **thoughtful instead of rushed**

Good software is not just code that runs.  
It’s code that still makes sense when the project grows, reality gets messy, and the bug goblins crawl out of the walls.
